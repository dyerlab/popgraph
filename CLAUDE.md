## Package Overview

`popgraph` is an R package for population genetics graph analysis using conditional genetic covariance topology. It constructs population graphs from multivariate genetic marker data via discriminant analysis and partial correlation, extends `igraph` objects with population-specific attributes, and provides ggplot2 visualization, spatial export, and statistical testing tools.

Install: `remotes::install_github("dyerlab/popgraph")`

## Build & Development Commands

```bash
# Check package (build + tests + documentation validation)
R CMD build . && R CMD check popgraph_*.tar.gz

# Generate/update roxygen2 documentation
Rscript -e 'roxygen2::roxygenise()'

# Run all tests
Rscript -e 'devtools::test()'

# Run a single test file
Rscript -e 'testthat::test_file("tests/testthat/test-popgraph.R")'

# Run tests matching a pattern
Rscript -e 'testthat::test_dir("tests/testthat", filter="congruence")'

# Load package for interactive development
Rscript -e 'devtools::load_all()'
```

## Architecture

**Core class**: `popgraph` extends `igraph`. Vertex attributes include name, size, coordinates. Edge attributes include weight. The asymmetric variant adds bandwidth (b_i) on vertices and directional weights (w_away, w_to) on edges.

**Key modules in R/:**

- **Constructors**: `popgraph.R` (main constructor — discriminant analysis → pairwise distances → partial correlations → edge testing), `as_popgraph.R` (convert matrix/igraph), `asymmetic_popgraph.R` + `assymetric_weights.R` (t-SNE inspired directional weights)
- **ggplot2 geoms**: `geom_edgeset.R`, `geom_nodeset.R`, `geom_edgelabels.R` — custom ggplot2 layers for graph visualization
- **Spatial converters**: `to_sf.R`, `to_SpatialLines.R`, `to_SpatialPoints.R`, `for_leaflet.R` — convert graph to spatial objects for mapping
- **Export**: `to_geojson.R`, `to_kml.R`, `to_json.R`, `to_html.R`, `write_popgraph.R`
- **Statistics**: `test_congruence.R`, `congruence_topology.R`, `permute_popgraph.R`, `randomize_graph.R`, `centroid_distance.R`, `centroid_variance.R`
- **Utilities**: `decorate_graph.R` (merge metadata into vertices), `overlay_popgraph.R` (combine graphs), `ops_popgraph.R` (operator overloading, e.g. graph subtraction)

**Bundled datasets** in `data/`: `lopho` (Lophocereus), `upiga` (Upiga), `baja` (population metadata), `alt` (altitude raster).

## Key Dependencies

- `igraph` — graph data structures and algorithms (core)
- `ggplot2` — visualization (geom layers)
- `sp` / `sf` — spatial data classes
- `MASS` — generalized inverse (`ginv`) used in graph construction
- `dplyr` / `magrittr` — data manipulation with pipes

## Conventions

- Documentation is roxygen2 inline (`#'` comments). Run `roxygen2::roxygenise()` after changing any roxygen blocks. Never hand-edit files in `man/`.
- NAMESPACE is auto-generated by roxygen2 — do not edit directly.
- Tests use `testthat` with `context()` grouping and `test_that()` blocks.
- Function naming: `to_*` for converters, `geom_*` for ggplot2 layers, snake_case throughout.
- The package uses S3-style dispatch with igraph objects rather than formal S4 classes.
